# Accessibility Requirements

## Reduced Motion

All animations must respect user preferences.

**CSS animations** — disable inside `@media (prefers-reduced-motion: reduce)`:
```css
@media (prefers-reduced-motion: reduce) {
  .animated { animation: none; transition: none; }
}
```

**JS animations** — skip if preference is set:
```js
if (!window.matchMedia("(prefers-reduced-motion: reduce)").matches) {
  // run animation
}
```

## Images

- All `<img>` elements must have a meaningful `alt` attribute
- Wrong: `alt=""`, `alt="image"`, `alt="hero.webp"`
- Decorative images only: use `alt=""` with `role="presentation"`

## Heading Hierarchy

- One `<h1>` per page
- Never skip levels: h1 → h2 → h3 (not h1 → h3)
- Headings convey document structure, not just visual size

## Interactive Elements

- All buttons and links must be reachable and activatable via keyboard
- Links must have descriptive text — avoid standalone "こちら", "詳細", or "click here"
- Use `<button>` for actions, `<a href>` for navigation

## Iframes

All `<iframe>` elements (e.g., MapFrame) must have a descriptive `title` attribute:
```html
<iframe title="会場へのアクセスマップ" src="..."></iframe>
```

## Color Contrast

- Normal text (under 18px / 14px bold): minimum 4.5:1 contrast ratio
- Large text (18px+ / 14px+ bold): minimum 3:1 contrast ratio
- Do not rely on color alone to convey information
